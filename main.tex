\begin{abstract}
Automated clustering is essential for mapping the rapidly expanding landscape of scientific literature, yet these systems remain incomplete if the discovered semantic hotspots cannot be interpreted reliably. Existing topic labeling and keyphrase extraction pipelines typically summarize clusters in isolation, producing redundant descriptors that fail to resolve the boundaries between closely related subfields. We introduce \textsc{TRENDSET}, a neighborhood-conditioned descriptor learning framework that jointly predicts descriptor sets for a target hotspot and its local semantic neighbors. \textsc{TRENDSET} optimizes a coupled objective: an assignment signal that encourages downstream document routing utility, and a determinant-based diversity regularizer that discourages semantic collapse. Methodologically, TRENDSET treats descriptor learning as a structured neighborhood prediction problem and realizes it through neighborhood-conditioned generation, assignment-based discrimination, and learned reranking over candidate descriptor neighborhoods. We evaluate the framework on a public multi-domain benchmark built from \texttt{arXiv}, \texttt{bioRxiv}, and \texttt{medRxiv}. Lexical exact-match metrics continue to favor extractive-style baselines, while the aligned 4-way public reruns show that routing-oriented utility is highly sensitive to evaluation protocol and neighborhood-size matching. These results support hotspot description as a local boundary-drawing problem and motivate future human evaluation beyond proxy routing metrics.
\end{abstract}

\section{Conclusion}

TRENDSET is built around a different prediction object from prior hotspot
labeling work: it predicts a neighborhood of descriptor sets whose
members jointly support local routing and resist semantic collapse. Across our
experiments, extractive systems still dominate lexical distinctiveness, while
the utility ranking becomes sensitive to the generator backbone and the exact
routing protocol. These results suggest that
scientific hotspot description is promising to study as a local decision
problem with both distinctiveness and utility in view, while fuller validation
will require human-centered evaluation.
