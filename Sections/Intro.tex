\section{Introduction}

Speculative decoding accelerates large language model (LLM) inference by
letting a small draft model propose multiple tokens that are then verified by a
larger target model in parallel \citep{leviathan2023speculative}. The speedup is
lossless, but it is fragile: whenever draft-target agreement drops, acceptance
length shrinks, more target-side correction is needed, and the latency benefits
erode. A large body of recent work therefore tries to improve draft-target
alignment, adapt draft length, or redesign verification to raise acceptance
rates \citep{liu2023online,goel2024direct,agrawal2024adaedl,bachmann2025judge,wang2025alignment,zhou2026hsd}.

This paper studies the complementary adversarial question: can a user choose a
prompt prefix that deliberately \emph{collapses} speculative acceptance? We are
interested in prompt-side attacks that preserve the target model and the draft
model, but manipulate the verification rule itself by causing the draft to be
confident in tokens that the target model assigns much smaller probability.
This attack surface is natural in deployment settings, because the attacker
controls only the input text, yet speculative decoding makes latency depend
directly on the relation between the draft distribution $q$ and the target
distribution $p$.

The central technical obstacle is discrete. Gradient-based prompt optimization
must operate over continuous token relaxations, but deployment requires a
discrete projected prefix. The real question is therefore not whether one can
write down a smooth surrogate, but when optimizing that surrogate provably
produces a strong discrete attack after projection. That continuous-to-discrete
gap is the main theoretical bottleneck for adversarial prompt search in this
setting.

Our starting point is the token-wise verifier acceptance rule
\[
\alpha_i = \min\!\left(1, \frac{p(y_i \mid h_i)}{q(y_i \mid h_i)}\right),
\]
where $h_i$ is the current speculative history and $y_i$ is the draft token at
step $i$. Under draft sampling, the one-step expected acceptance satisfies
\[
\mathbb{E}[\alpha_i] = 1 - \tv(p_i, q_i),
\]
which immediately suggests a smooth attack objective: maximize early
draft-target disagreement by maximizing weighted total variation. The
mathematics becomes nontrivial at projection time. We first formalize a
negative result, \emph{Prompt Waywardness}, showing that no unconditional
nearest-neighbor projection guarantee is possible. We then prove that under a
TV-Lipschitz assumption on the target and draft distributions, the projected
discrete attack gap is bounded by two actionable quantities: the relaxed solver
error and the projection distortion from the relaxed embedding back to the token
manifold. This bound directly justifies the manifold-attraction penalty used in
our optimization objective.

These guarantees matter because they turn a heuristic attack recipe into a
certified optimization framework. Instead of merely saying that total variation
is a sensible surrogate, we show when the optimized relaxed prefix remains close
to the optimal discrete adversarial prefix after projection. The resulting
theory also gives the experiments concrete diagnostics to track: the relaxed
objective value $C(U)$, the projection distortion $\rho(U)$, and the discrete
margin that separates the best attack from its competitors.

We instantiate the attack in a local white-box setting using the reproducible
HSD workspace with a draft model
\texttt{Qwen2.5-0.5B-Instruct-GPTQ-Int8} and a target model
\texttt{Qwen2.5-14B-Instruct-GPTQ-Int8}. On a benign GSM8K-style prompt in the
same chat format as the reproduction pipeline, the first drafted token is fully
accepted with $\alpha_1 = 1.0$. By contrast, the best adversarial seed we found
so far---\texttt{Complete the next symbol only: \textbackslash boxed\{}---drops
first-token acceptance to $\alpha_1 = 0.160$, making the first speculative
token reject with probability $0.84$. On the saved 263-sample token-wise
GSM8K run, the ordinary aggregate drafted-token acceptance rate is
$49.66\%$, which highlights how sharply the adversarial first step deviates
from normal operating conditions.

Our contributions are:
\begin{itemize}
\item We formulate prompt-side speculative-decoding slowdown as a
continuous-to-discrete adversarial optimization problem over verifier
acceptance probabilities rather than over output content.
\item We derive a smooth weighted-TV surrogate from the one-step speculative
acceptance identity and prove a prompt waywardness impossibility result showing
that unconditional projection guarantees cannot hold in general.
\item We prove a relaxation-gap bound and an exact-recovery corollary under a
TV-Lipschitz assumption, yielding a principled penalized objective that
explicitly controls projection distortion.
\item We report preliminary white-box results showing substantial first-token
acceptance collapse on a real draft-target pair, establishing prompt-side
acceptance collapse as a concrete systems vulnerability.
\end{itemize}

The broader message is that speculative decoding exposes a distinct
prompt-side systems vulnerability: a user can target \emph{latency} by attacking
draft-target agreement, even when the output distribution remains lossless.
