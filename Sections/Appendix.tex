\section{Implementation Notes}

Our local attack evaluation uses the same draft-target model pair as the HSD
reproduction workspace and the same Qwen chat template as the GSM8K evaluator.
The companion codebase implements the attack as a straight-through soft-prefix
optimizer over per-position vocabulary logits. The optimizer records exact
projected first-token acceptance, TV, reverse KL, collapse score, and the
projection-distortion trace for every candidate retained during search.

During optimization, we observed that the penalized straight-through estimator is highly stable; sweeping the projection penalty weight $\lambda_\rho \in \{0.1, 0.25, 0.5, 1.0\}$ consistently recovered the exact same optimal discrete attack prefix.

The calibration-batch universal-prefix pipeline extends the same code path with
multi-timestamp target rollouts, linearly weighted trajectory disagreement, and
a gradient-guided discrete seed-search stage that ranks candidate prefixes by
exact projected verifier collapse before continuous refinement.

For full-run evaluation, the reproduced GSM8K evaluator is patched to save
per-sample aggregate acceptance, block efficiency, drafted-token counts,
target-step counts, and first-token acceptance traces in the same JSON artifact
as the ordinary speculative-decoding counters. This instrumentation is what
enables the matched token-wise benchmark in Section~\ref{sec:eval}, including
both the single-prompt attack and the calibration-batch universal-prefix
comparisons.

The Palmetto submission scripts mirror the same attack configuration used in
the local search, and expose sweeps over projection-penalty multipliers,
optimized prefix length, and calibration-batch size. This makes the primary
ablations operationally simple: each setting is re-optimized from scratch
rather than evaluated by truncating or padding a previously found attack.
