\section{Implementation Notes}

Our local attack evaluation uses the same draft-target model pair as the HSD
reproduction workspace and the same Qwen chat template as the GSM8K evaluator.
The companion codebase implements the attack as a straight-through soft-prefix
optimizer over per-position vocabulary logits. The optimizer records exact
projected first-token acceptance, TV, reverse KL, collapse score, and the
projection-distortion trace for every candidate retained during search.

For full-run evaluation, the reproduced GSM8K evaluator is patched to save
per-sample aggregate acceptance, block efficiency, drafted-token counts,
target-step counts, and first-token acceptance traces in the same JSON artifact
as the ordinary speculative-decoding counters. This instrumentation is what
enables the matched benign-boundary versus attacked-boundary comparison in
Section~4.

The Palmetto submission scripts mirror the same attack configuration used in
the local search, and expose sweeps over both the projection-penalty multiplier
and the optimized prefix length. This makes the next ablations operationally
simple: each length is re-optimized from scratch rather than evaluated by
truncating or padding a previously found attack.
